A desktop HUD and terminal for developers who run many AI coding sessions at once — Claude Code, Codex,
Antigravity and others — side by side.

macOS 13+ (Apple Silicon; Intel and Windows builds coming) · MIT licensed · built with Tauri 2 + Svelte 5

## What it does

- **Every session on one screen.** Live status for each chat — `working`, `your turn`, `needs you` — with context
  usage, model, effort, tool calls, sub-agents, files touched and an API-equivalent cost. Read-only: the app never
  writes to your tools' data.
- **orbit.map.** A live 3D map: sessions orbit a HUD core (tools/min, cache, 5-hour and weekly limits), tool
  stations light up as they are used, and running dev servers (`npm run dev`, `cargo run`, `uvicorn` …) drive around
  as cars.
- **Terminals that survive.** Every terminal runs in a background session host: close the window or update the app and
  your AI keeps working. Tabs, splits, iTerm2-style keys, drag-and-drop images to Claude.
- **Panels.** research.feed (web searches), files.heat (and "same file" warnings when two chats edit one file),
  tool.mix, workers, spend.ledger (30 days of spending), session.log.
- **Source Control.** A VS Code-style Git panel: stage, diff and code viewer, blame, graph, commit, push and sync with
  your own `git` — plus **✧ AI commit messages** written by your own Claude Code subscription.
- **Themes.** Thirteen dark themes plus a signature theme; your AI tools can follow the terminal palette.
- **Social (optional).** Hacker name, friends, end-to-end encrypted messages, XP and wizard-guild ranks, a weekly
  leaderboard and announcements.
- **Token savers.** One-click rtk and caveman setup.

Privacy first: your sessions, code and prompts never leave your computer. See [PRIVACY.md](PRIVACY.md).

## Build from source

Requirements: Rust (stable, edition 2024), Node.js ≥ 22.18, and on macOS the Xcode command-line tools.

```sh
cd apps/desktop/web
npm install
npm run tauri -- dev        # run the app (Vite on :1420 + Rust)
npm run tauri -- build      # build an installer
npm run dev                 # UI only, in a browser with demo data: http://localhost:1420
```

From the repository root:

```sh
cargo test
cargo clippy --all-targets -- -D warnings
```

The social server lives in [`server/`](server) (Fastify 5 + Postgres; `npm run dev` uses an embedded database).
Deployment notes are kept privately, outside the repository.

## Repository layout

```
apps/desktop/src-tauri   Rust: engine (read-only session reader), terminal host, git, social client
apps/desktop/web         Svelte 5 UI: panels, orbit.map (three.js), terminal windows (xterm.js)
packages/shared          rules shared by the app and the server (XP, levels, ranks)
server                   social server
```
